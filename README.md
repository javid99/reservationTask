# پنل مدیریت رزروها — مجموعه خدماتی رزرواسیون

پنل ساده و فارسی (RTL) برای مدیریت رزروهای یک مجموعه خدماتی؛ شامل صفحه ورود، داشبورد آماری، جدول رزروها و ثبت رزرو جدید.

## اجرای پروژه

```bash
npm install
npm run dev
```

سپس در مرورگر آدرس `http://localhost:5173` را باز کنید.

## اطلاعات ورود آزمایشی

- ایمیل: `admin@panel.ir`
- رمز عبور: `admin1234`

## امکانات

- صفحه ورود با اعتبارسنجی فیلدها و نمایش خطا (احراز هویت نمایشی، بدون بک‌اند)
- داشبورد با کارت‌های آماری (کل رزروها، رزروهای امروز، در انتظار تایید، تایید شده)
- جدول رزروها با ۱۲ رزرو نمونه و نمایش تاریخ شمسی
- جست‌وجوی مشتری بر اساس نام یا شماره تماس
- فیلتر رزروها بر اساس وضعیت
- مشاهده جزئیات هر رزرو و تغییر وضعیت آن (تایید / انجام شد / لغو)
- فرم ثبت رزرو جدید در Modal با اعتبارسنجی فیلدهای ضروری
- پیام‌های موفقیت و خطا (Toast)
- ریسپانسیو: جدول در دسکتاپ و کارت در موبایل

## تکنولوژی‌ها

- React + TypeScript + Vite
- Tailwind CSS v4
- فونت وزیرمتن
